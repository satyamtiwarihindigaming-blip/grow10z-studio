# QA & publish

## Checklist (tick with evidence, file paths or ffprobe output)
- [ ] 1080×1920, 30 fps, 30–45 s (Shorts ≤ 60 s), H.264 + AAC
- [ ] Loudness −14 LUFS ±1, true peak ≤ −1.5 dB
- [ ] Captions inside safe zone; human-proofread Devanagari; no overlap with key action
- [ ] Hook in first 3 s; cliffhanger last 4 s; comment-bait question present
- [ ] Character consistency contact sheet passed
- [ ] No copyrighted music/visuals; `asset_log.md` updated; no real brands/people/crimes; family-safe
- [ ] AI-voice/synthetic-content disclosure added where the platform requires it
- [ ] Watch the full video once at phone size

## Post copy (`epNN_postcopy.md`)
Title ≤ 70 chars with curiosity gap · 2-line caption · 5–8 hashtags (mix: #हिंदीकहानी #सस्पेंस #आगेक्याहोगा + 2–3 niche) · pinned comment asking for guesses · next-episode teaser line.

## Publishing notes
Upload the same file natively to Reels and Shorts (no watermarks from other apps). Keep a `project/posting_log.csv` (date, ep, platform, link, 24 h views/likes/comments) to learn what works. Check current YouTube policy on repetitive/mass-produced and AI-generated content before relying on monetization.
